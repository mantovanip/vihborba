# Vi Borba

> Site institucional e de apresentação digital desenvolvido pela **Mantovani SYS** para o projeto Vi Borba.

## Visão geral

O projeto centraliza apresentação, informações públicas, conteúdo social e canais oficiais em uma experiência web responsiva.

## Recursos implementados

- Landing page responsiva
- Apresentação da marca/projeto
- Conteúdo institucional
- Destaque para redes sociais
- Integração com canais oficiais
- Navegação por seções
- Conteúdo multimídia
- Favicon
- Web App Manifest
- SEO básico
- Área de conteúdo/reels
- Chamadas para redes sociais
- Experiência mobile
